# Resolve API：確認できた動作と注意点

2026-10-07、なつみのResolve 21.1で実配置・保存・読戻しを行った時の知見。環境や呼出し方による差があるため、普遍的なSDK仕様と断定しない。公式MCPを優先し、案件で明示許可がある時だけ既存ResolveのScript APIを利用する。

| 観測した問題 | 確認できた対処 | 別環境で確かめる点 |
|---|---|---|
| 動画のendFrameを予定終端から1減らすと隙間が出た | この呼出しでは startFrame=s, endFrame=e で予定の区間尺になった | 最初の実追加1件のソース範囲・TL尺を読む。SDK一般の終端定義と混同しない |
| ソース29.97とTL59.94のフレーム単位が違う | 同じ実時間はTL側で2倍のフレーム数。GetLeftOffset(true)も単位を照合 | 素材fps、TLfps、速度変更、丸め。丸められた開始値だけで不一致としない |
| SRT追加がrecordFrameを無視してTL末尾へ入った | 空作業TLでは字幕を先に置き、動画を同じ開始位置へ配置。追加ブロックは実末尾の相対SRT位置を確認してから映像を追加 | import/append経路、字幕トラック、既存末尾、開始TC。読戻し無しで採用しない |
| 字幕改行の読戻しがU+2028になった | 文言比較時に改行を正規化 | 表示まで正常か別に確認 |
| GH6の原音が1映像に4音声クリップになった | チャンネル対応と同期を照合 | 4重再生による音量増大、必要なチャンネル、実音 |
| 静止画取得で字幕を確認できない経路があった | 実TLデータと利用可能なResolveビューアを併用 | 静止画にどのトラック・グレードが含まれるか |
| タイムアウト時に変更の成否が分からない | 実TLを読み、既存一致部分を保持して差分を再開 | 追加の二重実行、古いオブジェクトハンドル |
| シーク直後に前クリップ画像が返る | 画像内容・時刻・IDと再取得の安定を確認 | 固定待機秒だけでは正しさを証明できない |

## 再実行できる処理の形

1. PJ/TLをIDで取得して、期待する対象と照合する。
2. 既存配置のソースと範囲、設定版を一括取得する。
3. 計画との差分だけを求める。
4. 対象が変わっていないことを確かめ、復元可能な1論理変更を適用する。
5. 計画とは別に実APIから結果を取得し、保存成功・配置・元TL保持を確認する。
6. 結果不明なら失敗とも成功とも断定せず、現在の状態を再取得する。

新規適用とフレーム取得を同じTLで競合させない。APIの実タイムアウトに収まる量に分ける。上の手順は設計であり、このリポジトリに汎用の自動編集実装が完成しているという意味ではない。

## 実証の範囲

なつみの2案件で185カット／字幕181、293カット／字幕280の配置・保存・読戻しを確認した。後者は既存197カットを保持し96カットを追加した。これを色・顔・音の全編品質完成、またはsonobe環境での同動作の証明へ広げない。

旧補助スクリプトには新しいMCPプロセスを起動するものや、上の終端／字幕位置問題を含むものがある。ファイル名だけで「検証済み共通ランナー」と扱わず、該当経路と副作用を確認する。新しいアプリの起動禁止中に起動用スクリプトを実行しない。

## 2026-10-08：字幕の追加位置と呼出し境界

同じ作業TLへの追加で、SRTの `recordFrame` 指定が無視され、字幕が意図した位置から全件ずれる挙動を再確認した。追加部分だけを戻して、同じスクリプト呼出し内でSRTを再挿入した場合も、字幕がTL頭へ入った。

確認できた修復手順は次のとおり。**修復対象は今回追加した部分だけ**とし、それ以前の映像・音声のID、ソース、範囲を保持した。

1. 修復前のTLを復元可能な形で保全し、今回の追加部分と既存部分をID・範囲で区別する。
2. 追加部分の修復操作後に保存し、そのAPI呼出しを終える。
3. 別のAPI呼出しで実末尾を再取得し、相対時刻のSRTを挿入する。字幕の絶対TL時刻と本文を読み戻す。
4. 字幕の実位置が一致した場合に、その次の呼出しで同じ開始点へ追加映像・原音を配置する。
5. 保存後、映像・原音・字幕の位置と本文、隙間、既存部分のID・ソース・範囲を照合する。

なつみ Resolve 21.1／既存Script APIでの観測。呼出しを分けた後に配置が一致したことは確認したが、Resolve内部の原因や他環境での再現性は未確定。固定待機秒を万能な対処にしない。正常に追加できているTLへ、この修復操作を予防的に行わない。

当該ラウンドでは12映像・12原音・12字幕を追加し、合計24映像・24原音・12字幕、映像/音声の範囲一致、隙間0、既存24アイテムの完全保持、保存結果trueを実読戻しで確認した。字幕1件は実ビューア表示も確認。全動作・音聴取・色・全字幕の見た目は未検証であり、全編完成ではない。7秒を超えた字幕6件は表示尺の修正項目として検収から担当へ戻した。
