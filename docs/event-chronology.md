# 取材全体の出来事を時系列HTMLに残す

2026-10-08のユーザー指定。なつみで最初に検証し、haruto・aniya・sonobeを含む店舗動画の本編編集の標準工程にする。取材開始から閉店・片付けまで、映像に映るささやかな出来事も記録する。色や字幕だけの部分修正で、無関係な全素材の再解析は始めない。

## 観察を採用カットから独立させる

編集に使った場面だけで一覧を作らない。開店前の準備、机・作業台・客席の拭き掃除、道具や器の準備、手洗い、洗い物、食材の搬入・補充・小分け、伝票、配膳・下膳、客の出入り、休憩・飲食、店員のまかない、営業中の追加仕込み、閉店後の片付け等、実際に見える出来事を残す。例は探索対象であり、映っていない出来事を作るための必須枠ではない。

別の動作・対象・状態変化は別イベントとして扱い、一本あたりの件数を制限しない。同じ動作の継続区間はまとめられるが、別の皿や別工程まで「繰り返し」で消さない。不採用になったイベントも観察一覧から消さない。

「まかない」「開店」「閉店」など意味や役割を含む語は前後の映像・既存取材情報と照合する。食べる動作だけなら「飲食」「まかない候補」、拭く動作だけなら「作業台を拭く」など、確認できた範囲で記す。最後の撮影時刻を閉店時刻と断定しない。

## 取材時計と映像内時刻を分ける

- 既存の全素材一覧を母集団にし、別カメラ、途中からの映像、短いファイル、読み取れない素材、重複候補を残す。名前・容量だけの一致を内容同一と断定しない。
- ファイル更新日時や名前の辞書順を撮影順の根拠にしない。撮影日、素材内秒、カメラの時刻コード・UTCメタデータ・章の順序を読み、出典と補正方法を保存する。
- 連続分割されたカメラ素材で全章のcreation_timeが同じことがある。章固有の時刻コードや連続尺と照合し、全章を同じ時刻に並べない。NDF/DFと実fpsを取り違えない。
- カメラ間の時計差・日付境界・UTC/JSTを照合する。未同期なら仮時刻と分かる表示にし、素材内秒から常に元映像へ戻れるようにする。仮の時計補正で元の観察時刻を書き換えない。

## 観察の進め方と未確認

既存の実観察・画像・動画解析応答を再利用し、未確認帯から進める。全素材を粗く見渡してから、変化点と小動作を前後付きで細かく確認する。粗い索引を作っただけで完了しない。

静止画間引きは観察の入口であり、サンプル間の短い動作・音は未確認。生成した画像数と実目視した画像数、粗観察と連続映像の確認を分ける。動画解析を使った場合も、実入力区間・速度・fps・音の有無・成功応答を記録する。全尺を送った事実だけで細部の網羅を認定しない。

確認できた出来事を既存HTMLへ逐次追加し、全てを見終えるまで利用できる一覧を隠さない。未確認帯、素材の欠落、読取エラー、未確定の開閉店時刻も同じ画面で見せる。「イベントなし」は当該区間を確認した場合のみ。「映像なし」「未確認」「暗く判別できない」と区別する。

## 案件側の最小データ

既存の観察台帳を拡張する。必要な項目は次のとおり。

- 素材ID、素材内開始・終了秒、安定したイベントID
- 仮の撮影時計と根拠、カメラ、時計補正・同期の状態
- 短い出来事名、区分、具体的観察、確定／候補
- 根拠画像の素材秒、元映像への参照、確認方法・範囲
- 観察の確認状態と、本編への採否・Resolve実反映状態（別々に保持）
- 未確認区間、読取失敗、重複候補と根拠

瞬間の静止画しか根拠がなければ、点観察として保存する。前後数十秒まで動作が続いたと捏造しない。境界を精査していなければ概算範囲とする。JSONから読戻し、文字化け・壊れた画像参照・範囲外の時刻を修正する。

## HTMLで見せるもの

同じ案件の既存確認HTMLを入口にし、時刻順の出来事カード／表、時刻・カメラ・種類・キーワードによる絞り込み、元映像の該当位置、前後の根拠画像、未確認帯を接続する。価格や台詞を勝手に補わない。

短い出来事が大量にあっても探せることを優先する。観察メモとユーザーの訂正・追加を保存復元できるようにし、再生成で消さない。HTMLのメモ変更とResolveへの反映を混同しない。全項目を読める一覧と、必要な範囲へ絞った表示を両立する。

## 引き渡しと検証

件数だけで完成としない。撮影開始側、営業前後、途中、終わり側と小動作の例を元映像へ戻して確認する。出来事の誤記、抜け、重複、時間のずれ、画像・再生リンク、検索・絞り込み、メモの保存復元を検証する。

最初のテストでは実装・実観察の範囲と残る未確認を報告する。全素材全イベントの網羅が未検証なら、そのまま明記する。手順修正と試験で分かった一般化可能な知見は同じGitHubへ毎回保存し、4台の入口から参照する。素材や顔画像を公開リポジトリへ載せない。新しい席・サービス・レンダーをこの工程のために無断で起動しない。
